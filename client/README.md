# Ground Control Station - Frontend

This directory contains the React frontend for the Ground Control Station project.

It was scaffolded using [Vite](https://vitejs.dev/) with the React template.

## Running the Frontend

To start the development server:

```bash
npm install
npm run dev
```

The application will be available at `http://localhost:5173`.

## Project Context

This frontend is designed to connect to the Node.js MAVLink bridge running on `ws://localhost:8080`.

For full architecture details, setup instructions, and startup commands for the entire stack (including ArduPilot SITL and the backend), please see the **[root README.md](../README.md)**.
